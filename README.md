# FitFlow Redesign

## Project Overview

FitFlow Redesign is a fitness application redesign project focused on improving the overall user experience and making fitness management easier for users.

The project includes a mobile frontend, backend API, AI service, and technical documentation used during the development process.

---

## Project Objectives

- Create a simple and user-friendly fitness application interface.
- Improve user interaction and usability.
- Organize the system into frontend, backend, and AI service components.
- Maintain proper documentation for technical decisions.

---

## Technologies Used

Frontend:
- React Native

Backend:
- Node.js
- Express.js

AI Service:
- Python
- FastAPI

Database:
- PostgreSQL

Documentation:
- Architecture diagrams
- Technology comparison matrix
- ADR documents
